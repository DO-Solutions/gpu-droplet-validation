gpu-model={{ .Values.gpuModel }} gpu-count={{ .Values.gpuCount }} image-version={{ .Values.image.version }}

This release created one INDEPENDENT single-node Job per target
({{ if .Values.targetNodes }}nodes: {{ join ", " .Values.targetNodes }}{{ else }}1 Job, scheduled by nodeSelector{{ end }}).

Per Job:

  # wait for completion (Never-restart Job; exit 1 is a valid result)
  kubectl -n {{ .Release.Namespace }} wait --for=condition=complete --timeout=2h job/<job-name>

  # TAP v14 (only emitted when ALL init stages succeeded)
  kubectl -n {{ .Release.Namespace }} logs job/<job-name> -c tap-reporter

  # full artifacts — copy BEFORE ttlSecondsAfterFinished ({{ .Values.ttlSecondsAfterFinished }}s) GCs the pod
  POD=$(kubectl -n {{ .Release.Namespace }} get pod -l job-name=<job-name> -o name | head -n1)
  kubectl -n {{ .Release.Namespace }} cp "${POD#pod/}":/results ./results

Hard-fail (prereqs/setup/rvs exit non-zero): tap-reporter never runs. The
partial /results (e.g. prereqs.json) still survives in the pod — copy it as
above and inspect, or use the wrapper which reconstructs TAP automatically.
